# 星载指令转码器 · 功能一致性审计服务

判断一个**带 ε 迁移与输出（每条迁移追加 0–2 个大写 ASCII 字符）的有限换能器**
是否**功能一致（functional）**：即是否存在输入符号串，能沿两条**可接受路径**
（初态出发、终止于接受态）产生**不同的下行字节串**。

"精确判断"意味着：

- **不限制输入长度**（证据可能需要泵浦 ε 环）；
- **不使用随机样本或有限路径枚举**；
- 不一致时给出输入串与两条**逐迁移路径**及各自输出，并按
  **（输入长度 → ASCII 序 → 路径迁移标识序）**稳定裁决出唯一的最佳反例。

## 判定原理（精确且必然终止）

在**状态对 + 输出滞后（lag）**的有限乘积自动机上做 Dijkstra 搜索：

1. 乘积节点 `(p,q)` 的边有三类：两边同消费一个输入符号（`sym`）、
   仅左路走 ε（`epsL`）、仅右路走 ε（`epsR`）。
2. 每步把两侧新增输出拼到滞后串上，消去公共前缀；两侧残余首字符不同即
   **永久分叉（conflict）**，再用输出无关的乘积 BFS 拼出到达接受态对的最小
   延续，即得完整反例。
3. 单侧滞后有界（初始 `2×最大输出长度`，溢出时翻倍加深，最多 64 轮）——
   超过界意味着存在**可泵浦的输出环**（自由幺半群泵浦引理），加深后必然
   产生具体反例；因此判定**不依赖任何输入长度上限**且必然终止。
4. 只扩展能到达"双接受态对"的节点（逆图可达性剪枝）；只有当两条路径
   **同处于一条游走**上再现同一状态对且滞后变化时才视为环，避免误判。
5. 最佳证据由二叉堆按 `(输入长度, 输入串 ASCII, 路径1标识序列, 路径2标识序列)`
   严格排序选取。

## 运行方式

### Docker Compose（推荐）

```bash
docker compose up --build -d
# 自定义宿主机端口：
PORT=9090 docker compose up --build -d
```

打开 http://localhost:8080 （或自定义端口）。结论持久化在命名卷
`audit-data`（`/data/audits` JSON 检查点，原子写入）。

### 本地直接运行（无第三方依赖，仅需 Node ≥ 20）

```bash
npm start                 # 默认 0.0.0.0:8080
PORT=9090 HOST=127.0.0.1 npm start
DATA_FILE=/tmp/audits.json npm start
```

## 一键验收

```bash
npm run verify                 # 测试 -> 镜像构建 -> compose up -> HTTP 冒烟，以退出码裁决
HOST_PORT=9090 npm run verify  # 指定宿主机端口
LOCAL=1 npm run verify         # 无 Docker 环境：对本地进程执行同一套 HTTP 冒烟
```

`verify` 针对一条**含 ε 迁移、双字符输出**的双输出反例（输入 `a`，
输出 `ABC` vs `XY`）完成：代码测试 → 容器构建 → 服务就绪 → 真实 HTTP 冒烟
（提交、冻结回放、换载荷 409、按标识重开、聚合校验错误 422），
全部通过退出码 `0`，任一失败退出码 `1`。

## HTTP API

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET`  | `/health` | 健康检查，与页面/存储状态相符（`status`、`persisted`、`page`） |
| `GET`  | `/` | 审计页面 |
| `POST` | `/api/audits` | 提交审计；合法返回 `201`，非法 `422`（一次返回全部错误，不持久化结论） |
| `GET`  | `/api/audits/:id` | 按稳定标识重开已持久化的审计 |
| `GET`  | `/api/audits` | 已持久化审计列表 |

**重传语义**：同一标识 + 同一载荷 → `200` 且 `replayed: true`，
直接回放冻结结论，不重新分析；同一标识 + 不同载荷 → `409` 拒绝。

## 前端行为

- 状态 ≤ 10、迁移 ≤ 30（超限与其它错误**一次全部列出**）；
- 重复状态、悬空端点、非法 ε（既非空也非 `ε`）、字母表外输入符号、
  空接受集等全部聚合报错；
- **任何编辑立即清除旧证据**，提示重新提交；
- 通过真实 `fetch` API 提交与重开；冻结结论以 🧊 标注；
- 页面内置反例样例按钮（ε + 双输出）与持久化审计快捷载入。
